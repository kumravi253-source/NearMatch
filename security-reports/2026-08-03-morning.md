- **uuid moderate-severity findings (11): FIXED.** Root cause was `uuid <11.1.1` ([GHSA-w5hq-g745-h8pq](https://github.com/advisories/GHSA-w5hq-g745-h8pq)) pulled in transitively via `xcode` → `@expo/config-plugins`. No clean upstream bump existed — both `@expo/config-plugins@57.0.6` and `xcode@3.0.1` were already the latest published versions of each, neither having moved to a patched `uuid`. Since `xcode`'s only use of `uuid` is `uuid.v4()` (unaffected by this advisory, which covers v3/v5/v6), added a `package.json` `overrides` entry pinning `uuid` to `^11.1.1` to force the transitive resolution. Verified: `npm ls uuid` now shows `xcode@3.0.1 → uuid@11.1.1`, and `npx expo prebuild --no-install` completed successfully, generating a valid `ios/NearMatch.xcodeproj/project.pbxproj` with well-formed UUIDs — confirming the override doesn't break native project generation. `npm audit` now reports 0 vulnerabilities.
