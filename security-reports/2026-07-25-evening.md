## Security Report Summary (from security-reports/2026-07-25.md)
**Overall status: 🚨 CRITICAL (at time of report, now fixed)**

Three critical/medium `SECURITY DEFINER` RPC privilege-escalation bugs were found and fixed today:
1. `get_wallet_balance_paise(p_user_id)` — leaked any user's real-money wallet balance to unauthenticated callers. **Fixed**: pinned to `auth.uid()`, `anon` revoked.
2. `get_user_id_by_email(p_email)` — public email→account-existence oracle, callable by anyone via `anon` key. **Fixed**: restricted to `service_role`.
3. `is_premium(p_user_id)` — leaked Premium subscription status for any UUID to anon callers. **Fixed**: pinned to `auth.uid()`.

All three verified live post-fix (anon calls now return 401/404).
