## The 60-second version

NearMatch is a location-aware dating app for the Indian market — React Native
(Expo SDK 57) on the front, Supabase (Postgres + Auth + Storage + Realtime +
Edge Functions) on the back, with a static marketing site at nearmatch.in.

It is **not launched**. Launch is set for **1 September 2026**. The iOS build
was submitted to App Review around 2026-08-03 and last confirmed as "Waiting
for Review"; that status has been unverifiable since 2026-08-07 because the
App Store Connect session used by the automated checks keeps expiring.

The codebase is small — 13 app source files, 34 migrations, 5 edge functions,
9 website files — but carries an unusually thorough operational record: 40
security reports and 8 functional health reports, mostly generated by daily
automated audits.

## How to read this

Each document states facts drawn from the repository, and is explicit about
what is **verified** versus **assumed** versus **unknown**. Where something
could not be checked, it says so rather than guessing. Dates are ISO
(YYYY-MM-DD); times are IST unless marked UTC.

## Keeping this current

These files describe a moving project and will drift. The parts most likely to
go stale first: launch status, App Review state, hosting (see document 6 —
actively mid-migration), and the open items in document 9. The parts least
likely to drift: architecture, schema, and the timeline.
